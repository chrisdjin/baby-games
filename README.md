# Baby Games 🐣

A tiny, self-contained web app of touch games for toddlers (~2–3 yrs).
Single `index.html`, no build step, no dependencies — just open it.

**Games:** Name It · Find It · Pop It · Colors · Count It · Match Pairs

Uses the browser's built-in speech + WebAudio. Best on a phone/tablet;
add it to the home screen for a fullscreen, app-like experience.
